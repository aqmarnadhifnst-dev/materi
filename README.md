# Website Penyimpanan Materi Pelajaran

Website sederhana untuk menyimpan dan mengorganisir materi pelajaran yang dihosting di GitHub.

## Fitur
- ✅ Menyimpan link materi GitHub
- ✅ Filter berdasarkan kategori
- ✅ Pencarian materi
- ✅ Responsif untuk mobile

## Cara Menggunakan
1. Buka website di: https://YOUR_USERNAME.github.io/website-materi-pelajaran
2. Klik "Tambah Materi" untuk menambah materi baru
3. Gunakan search box untuk mencari materi
4. Filter berdasarkan kategori menggunakan tombol filter
